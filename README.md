Скрипт для генерации правил RoutingA для обхода российских блокировок на основе данных opencck.org.
rules и .cache не находятся в gitignore в целях отказоустойчивости, чтобы даже если чё-то не сработало все нужные данные поставлялись вместе с репозиторием.
Поддерживает только ipv4! Если ваш провайдер поставляет ipv6 наравне с ipv4 (так делают мобильные, например), отключите ipv6 в настройках сети вашего устройства.
